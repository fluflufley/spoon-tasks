Import tasks

Use a CSV file (in Excel or Google Sheets: save/download as CSV), or copy the cells from your spreadsheet and paste them below. Put headers in the first row: Task, Category, Type (business or pleasure), Term, Priority, Spoons, Status, Date, Reminder (date and time). Only Task is required. Priority and spoons run 0–7, and dates work best as YYYY-MM-DD. Imported tasks are added to your existing ones.
